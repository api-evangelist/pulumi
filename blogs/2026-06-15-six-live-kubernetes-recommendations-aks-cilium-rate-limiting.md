A live workshop demonstrated AKS cluster creation with Cilium eBPF networking, Azure Container Registry integration, and Kubernetes workload deployment using C#. The session hit Docker Hub rate-limiting mid-demo and adapted by switching to Azure Container Registry builds. Recommendations include using your team's preferred language for infrastructure code, enabling Cilium on AKS, splitting infrastructure from workloads across separate stacks, leveraging existing Terraform modules during migration, and implementing GitOps patterns with Argo CD.
