Today we’re introducing Pulumi Neo code reviews , now in public preview. Neo code reviews analyze pull request changes in conjunction with what Pulumi Cloud knows about your running infrastructure, providing both high-level and code-level feedback. Normal code review agents can’t reliably anticipate the impact an infrastructure-as-code change will have.
