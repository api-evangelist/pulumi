Pinned to an older Pulumi CLI or SDK version and finding that the docs describe a newer release? The Pulumi CLI command reference and the SDK API docs now include a version selector, so the documentation you’re reading matches the version you’re actually running. How it works When you open the CLI command reference , you’ll see a version dropdown near the top of the page, below the title.
